- Fix for background startup detection with Pixelcade and LED only systems

1.09 16/3/26

- Add logic to direct Mame explosion animations to either Pixelcade LED or LCD displays with a default logic and ability to override to specific displays with PIXELCADE_EXPLOSIONS_DISPLAYS=

1.06 27/1/26
- Fix bug where Mame credit monitoring was not being reset in between games
- Make joysticks open and number in a more logical order.  Now DOFLinx joystick numbers are in the same order as Linux starting from 1.
  So /dev/input/js0 = Joystick #1, /dev/input/js1 = Joystick #2 and so on.
- Change the loading of buttons to allow assignment of input to joysticks that are not connected at the time of startup
- Fix case sensitivity of USES in MAME files
- Enhance the logic for FBNeo memory reads for later games using little endian words
- Add an optional score modifier for Pixelcade score format to allow for fast large scores like AfterBurner 2

1.05 8/1/26
- Sort out Attract Mode commands for Pixelcade LED sub displays and Pulse
- Fix Retroarch activation to only activate for FBNeo
- Fix RGB undercab crash when no RGB devices are defined
- Improve Attract Mode MORPH logic to avoid flooding the output controller with the number of updates after changes
- Fix PS Pico command for 60 port change

1.04 3/1/26
- Fix crashing of turning on colour LEDs if the Green / Blue ports go beyond the last output port by setting Red as the last output port
- Add support for PacLED64 and Ultimate I/O.
  Requires use of the Ultimarc script to secure ports via udev and the DOFLinx support program dplc
- Clear the Pixelcade Pulse effects when shutting down
- Add support for operating specific parameters to INI files
- Add RGB and mono buttons, joystick and trackball illumination at game start to many MAME games
- Make Pixelcade LED attact marquees not trigger Pulse or mini screen
- Fix KEY_TO_COMMAND= when its blank just to clear previous loadded commands
- Fix loading of Pixelcade with DOFLinx marquee to stop Pulse effects
- Get the Pixelcade bindPort for LED device from pixelcade.ini
- Stop MAME FF_MSG running before the plugin is fully loaded (Galaxian issue with ROM startup)

1.03 12/11/25
- Fix overflow and other strange errors errors with KEY_TO_OUTPUT_TIMER, KEY_TO_OUTPUT, KEY_TO_COLOUR_TOGGLE, OUTPUT_NOW_TIMER, BUTTONS_ON, FIXED_OUTPUTS, BUTTONS_ON_COLOUR, FIXED_OUTPUTS_COLOUR, ATTRACT_SETUP, LINK_ITEMs, LINK_BUTTONSs, and a few others for output ports > 127
- Add LINK_BUT_TB1 and LINK_BUT_TB2 for RGB trackballs one and two
- Add PIXELCADE_SCORE_DISPLAYS_P1 and _P2 to be able to manually set the displays for MAME P1 and P2 scores.  For most people the defaults will be OK.
- Add detection of the main Pixelcade Pulse matrix size and use that to call size specific effects for items like MAME explosions, etc
